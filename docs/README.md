# docs/

核对来源写在每篇的开头。要改这些文档时，先对着代码核一遍。

## 读法

- **第一次来**：[architecture.md](architecture.md) 读完就够动手了，其余按需要查。
- **改代码前**：翻到对应那篇的「已知未做」一节，多数坑已经写在别的文档里了。
- **加 RPC**：[process-and-ipc.md](process-and-ipc.md) §4 是完整方法清单，加完记得同步那张表。
